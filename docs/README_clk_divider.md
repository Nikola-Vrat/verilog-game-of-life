# Описание модуля clk_divider

## 1. Назначение модуля

Модуль `clk_divider` предназначен для формирования периодического управляющего импульса, используемого для запуска перехода игры «Жизнь» к следующему поколению.

Входной тактовый сигнал `clk` имеет высокую частоту. Если передавать его непосредственно в модуль `game_logic`, новое поколение будет формироваться слишком часто. Поэтому модуль `clk_divider` подсчитывает количество тактовых импульсов и через заданный промежуток времени формирует короткий импульс `cr_new_gen`.

Таким образом, модуль выполняет функцию делителя частоты и генератора импульса перехода к следующему поколению.

## 2. Параметр модуля

Модуль содержит параметр:

```verilog
parameter integer COUNT_MAX = 50_000_000
```

`COUNT_MAX` задаёт количество тактов входного сигнала `clk`, после которого должен быть сформирован импульс `cr_new_gen`.

При значении:

```text
COUNT_MAX = 50 000 000
```

и тактовой частоте:

```text
fclk = 50 МГц
```

один импульс `cr_new_gen` формируется примерно один раз в секунду.

Параметр `COUNT_MAX` можно изменить, чтобы изменить скорость работы игры.

## 3. Входные сигналы

### `clk`

Основной тактовый сигнал модуля.

На каждом положительном фронте `clk` увеличивается значение внутреннего счётчика `counter`.

### `rst`

Сигнал сброса.

При его активации счётчик устанавливается в ноль, а выходной импульс `cr_new_gen` устанавливается в `0`.

## 4. Выходной сигнал

### `cr_new_gen`

Сигнал перехода к следующему поколению.

Он принимает значение `1` только на один тактовый период, когда счётчик достигает заданного значения `COUNT_MAX - 1`.

После этого счётчик сбрасывается и начинается новый отсчёт.

## 5. Внутренний счётчик

Для подсчёта тактов используется регистр:

```verilog
reg [27:0] counter;
```

Счётчик имеет ширину 28 бит.

Он хранит количество тактовых импульсов `clk`, прошедших с момента последнего сброса счётчика.

При каждом такте, если максимальное значение ещё не достигнуто, выполняется:

```verilog
counter <= counter + 1'd1;
```

Таким образом счётчик последовательно увеличивается.

## 6. Основной синхронный блок

Основная логика модуля находится в блоке:

```verilog
always @(posedge clk or posedge rst) begin
```

Блок срабатывает при одном из двух событий:

- положительном фронте `clk`;
- положительном фронте `rst`.

Это означает, что сброс является асинхронным относительно тактового сигнала.

## 7. Сброс модуля

При активации `rst` выполняется:

```verilog
if (rst) begin

    counter <= 28'd0;

    cr_new_gen <= 1'b0;

end
```

Счётчик устанавливается в ноль:

```text
counter = 0
```

Одновременно выходной сигнал устанавливается в ноль:

```text
cr_new_gen = 0
```

После снятия сброса начинается новый отсчёт тактов.

## 8. Достижение максимального значения счётчика

Следующее условие:

```verilog
else if (counter >= COUNT_MAX - 1) begin
```

проверяет, достиг ли счётчик необходимого значения.

Если условие выполняется:

```verilog
counter <= 28'd0;
cr_new_gen <= 1'b1;
```

Счётчик сбрасывается:

```text
counter = 0
```

а `cr_new_gen` устанавливается в `1`.

Это означает, что наступил момент перехода игры к следующему поколению.

## 9. Формирование однократного импульса

На следующем такте условие `counter >= COUNT_MAX - 1` уже не выполняется, поэтому выполняется:

```verilog
else begin

    counter <= counter + 1'd1;

    cr_new_gen <= 1'b0;

end
```

Таким образом, `cr_new_gen` снова становится равным `0`.

В результате получается импульс длительностью ровно один такт.

Сформированный сигнал `cr_new_gen` передаётся в модуль `game_logic`.

Когда `clk_divider` формирует импульс `cr_new_gen`, модуль `game_logic` выполняет:

```verilog
else if (cr_new_gen) begin

    for (r_idx = 0; r_idx < H; r_idx = r_idx + 1) begin

        current_grid[r_idx] <= next_grid[r_idx];

    end

end
```

Таким образом, `clk_divider` определяет скорость смены поколений, а `game_logic` выполняет сам расчёт нового поколения.
