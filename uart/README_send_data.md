# Serial Echo Test (Тест эха последовательного порта)

Скрипт на Python для проверки целостности передачи данных через последовательный порт (COM-порт). 
Программа генерирует тестовый пакет данных, отправляет его побайтово в порт и сравнивает с тем, что возвращается (эхо).

## Описание работы

1. Генерируется пакет из **15 байт**: 
   - 2 байта заголовка (`0x55`, `0xAA`).
   - 13 байт случайных данных (Payload).
2. Открывается COM-порт с настройками по умолчанию (`115200`, 8N1).
3. Скрипт отправляет по одному байту и сразу ожидает его возврата (чтение 1 байта).
4. Если на каком-то байте происходит таймаут (ожидание более 1 секунды), программа прерывается и указывает, на каком именно байте произошла ошибка.
5. В конце выводится два HEX-дампа (отправленные и полученные данные) для наглядного сравнения, а также результат проверки.
